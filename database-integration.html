Relational Data Model

Five Core Persistent Storage Domains

Strict foreign-key integrity, composite indexing, and JSONB metadata columns built to satisfy Central Bank and Financial Intelligence Unit record-keeping mandates.

TABLE: Customer

Customers & KYC Profiles

Stores verified individual and corporate identities, beneficial ownership structures, PEP/sanctions statuses, and dynamic AML risk ratings.

  • • id: UUID @id @default(uuid())
  • • nationalIdHash: String @unique
  • • kycTier / amlRiskScore: Int
  • • eddRequired: Boolean
TABLE: Transaction

Financial Transactions

High-throughput ledger records capturing payment amounts in Decimal precision, channels, counterparty details, and real-time fraud scores.

  • • id: UUID @id @default(uuid())
  • • amount: Decimal(18, 2)
  • • channel / currency: String
  • • decisionStatus: Enum (ALLOW/BLOCK)
TABLE: Alert

AML & Fraud Alerts

Links suspicious transactions and behavioral anomalies to specific rule codes, severity weights, and deduplicated alert queues.

  • • id: UUID @id @default(uuid())
  • • ruleCode: String (Indexed)
  • • severity: Enum (LOW..CRITICAL)
  • • ruleSnapshot: Json
TABLE: Investigation

Forensic Investigations

Tracks analyst assignments, SLA deadlines, documentary evidence attachments, MLRO sign-offs, and STR/CTR regulatory filing references.

  • • caseNumber: String @unique
  • • assignedAnalystId: String
  • • disposition: Enum
  • • strFilingRef: String?
IMMUTABLE TABLE: AuditRecord

Cryptographic Audit Records

Append-only compliance ledger recording every state mutation, risk score override, analyst note, and regulatory export—complete with actor ID, IP address, before/after JSON diffs, and SHA-256 integrity hashes.

• actorId & actorRole: String
• entityType & entityId: String
• previousState / newState: Json
• integrityHash: String (SHA-256 Chain)

                        Sensitive identifiers (National IDs, passport numbers, account numbers) are encrypted via AES-256-GCM before database insertion while preserving deterministic HMAC hashes for exact-match indexing.
